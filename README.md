# 🤖 CypherBot

CypherBot is a Telegram AI assistant with developer tools,
file processing, automation, moderation, games, and FREE/PRO
feature access.

## Features

- AI assistant
- Developer tools
- JSON formatter
- Base64 encoder
- QR generator
- FREE usage limits
- SQLite database
- Render deployment support

## Commands

/start
/help
/menu
/ask
/json
/base64
/qr
